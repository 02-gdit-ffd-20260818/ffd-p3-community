# 第 12 次课教师指南｜P3 v1.1 搜索与图谱

## 前置基线

从 `p3-v1.0` 开始，保留授权白名单、画像卡片和所有隐私测试。本增量只解决“怎样找到合适成员”和“当前结果有哪些技能”。

## 三段演示

1. 先运行 `filterMembers`：输入城市、角色、英文技能和无匹配词，核对列表数量。
2. 再运行 `aggregateSkills`：在 Console 检查 `API=2`、`CSS=3`，证明图表数据来自原始成员数组。
3. 最后接入 ECharts：筛选 `API` 时，列表和图表同步变化；清除条件后同时恢复。

## 易错点

- 把技能下拉和关键字做成“或”关系，导致结果范围反而变大。
- 单独手写图表数组，成员修改后图表仍显示旧数字。
- 图表容器没有高度，页面只剩空白。
- 只画图不提供文本摘要，读屏用户无法获得等价信息。
- 忘记 `resize` 或 `dispose`，窄屏错位或重复挂载泄漏。

## 发布门

运行 `npm run check`、`npm test`、`npm run build`；CI 绿色后由 Netlify 自动 CD 发布同一固定 URL，再建立 `p3-v1.1` Release。
