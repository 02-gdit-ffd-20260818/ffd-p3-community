# 第 12 次课教师指南｜P3 v1.0 成员画像

## 本课只完成什么

完成字段字典、授权边界、画像卡片、公开详情、空值与图片失败处理，并发布 `p3-v1.0`。搜索筛选和图表留给 v1.1 增量。

## 三学时落地

1. 第 1 学时：阅读 User Story，删掉不必要字段；讲解公开白名单与授权状态为什么不能一起下发。
2. 第 2 学时：完成 `normalizeMember`、`MemberCard`、列表和详情；用缺字段与失效图片调试。
3. 第 3 学时：运行 `npm run check && npm test && npm run build`，推送并等待 CI，记录 Release 与 Netlify URL。

## 教师演示顺序

1. 先把一条记录的 `profileConsent` 改为 `false`，证明它不进入公开列表。
2. 再观察苏禾的失效头像如何回退成姓名文字。
3. 清空地点、简介、技能或兴趣，解释“没有数据”和“代码出错”的区别。
4. 打开窄屏，检查标题、卡片和详情抽屉。

## 验收证据

- 13 项结构检查。
- 5 项领域单元测试与 3 项组件测试。
- 生产构建成功、GitHub Actions 绿色、`p3-v1.0` Release。
- Netlify 固定 URL 可匿名访问，首页与静态资源返回 HTTP 200。
